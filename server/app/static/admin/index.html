Обзор

Всё ли готово, чтобы игроки зашли на сервер через лаунчер.

    Моды

    Сервер

    С этим профилем лаунчер ставит Minecraft и подключается к серверу.

    После сохранения лаунчеры игроков при следующем запуске заново поставят Minecraft под этот профиль.

    Добавить моды

    Перетащите .jar сюда или нажмите, чтобы выбрать

    Можно сразу несколько файлов

    Тип для всех

      Изменить мод

      Тип

      Сам jar-файл не меняется. Чтобы заменить его, удалите мод и загрузите заново.

      Удалить мод?

      Мод пропадёт из базы и файл будет удалён с сервера. Игроки перестанут получать его при следующей синхронизации. Отменить удаление нельзя.
