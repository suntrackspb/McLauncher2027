Обзор Моды Сервер Управление

Обзор

Всё ли готово, чтобы игроки зашли на сервер через лаунчер.

    Моды

    Сервер

    С этим профилем лаунчер ставит Minecraft и подключается к серверу.

    После сохранения лаунчеры игроков при следующем запуске заново поставят Minecraft под этот профиль.

    Подключение к серверу

    Через него админка кладёт на сервер моды из профиля и наш authlib. FTP — если сервер у хостера с панелью (сам сервер ставит панель). SFTP — свой сервер с доступом по SSH.

    Синхронизация с сервером

    Сначала покажу, что изменится. Лишние моды не удаляются, а уходят в mods_removed/, оригинальный authlib сохраняется рядом как .orig. После применения перезапустите сервер.
